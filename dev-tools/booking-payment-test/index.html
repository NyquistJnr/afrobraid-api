Booking + payment test harness

Throwaway dev tool, not part of the app. Walks through the real booking-calculations → bookings → Stripe confirm → webhook flow against your local API.

Serve this folder over http://localhost:5500 (already in CORS_ORIGINS — e.g. VS Code's "Live Server" extension, or python -m http.server 5500), don't just double-click the file — opening it as file:// sends no CORS origin and the API will reject the requests.

For step 6 to actually flip the booking to CONFIRMED, you also need running in a terminal:
arq app.worker.WorkerSettings
stripe listen --forward-to localhost:8000/api/v1/webhooks/stripe/payments
